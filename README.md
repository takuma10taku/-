# LA活動支援専用WEBアプリ（モック）

要件書に基づくシングルページモック実装です。

## デモ画面へのアクセス方法

### 方法1: ファイルを直接開く（最短）
1. `index.html` をブラウザで開く

### 方法2: ローカルサーバー経由で開く（推奨）
1. このリポジトリ直下で以下を実行
   ```bash
   python3 -m http.server 8080
   ```
2. ブラウザで `http://localhost:8080/index.html` にアクセス
